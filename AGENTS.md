# Repository instructions

This is a J613 research log and read-only diagnostic toolkit, not an installer.
Keep tested observations separate from hypotheses, source claims and untested
features. Retain the exact board, firmware and package scope for every result.

Never add calibration, firmware, keybags, Catacombs, account identifiers, raw
device trees, full journals, packet captures or disk images. Inspect files
explicitly before committing; do not copy the private working research folders.

Tools default to read-only behavior and emit selected fields. Hardware changes
need a named board, preserved recovery route and independent runtime checks.
Do not disable thermal or speaker protection or raise clocks to make a check pass.

Do not modify packaged Omarchy files. Keep original work and upstream code
separate, preserving licenses and attribution. A result here is not an upstream
support claim. Keep system repairs separate from the T2Touch product.
